# 🧠 Mental Models Engine

受查理·芒格（Charlie Munger）启发的多元思维模型决策与投资认知框架。

**Mental Models Engine** 是一个面向 AI Agent 的长期主义金融认知系统，用于：

* 投资分析
* 商业判断
* 资本配置
* 财经信息理解
* 概率决策
* 多学科推理

它并不是普通聊天机器人。

系统核心目标是：

> 将查理·芒格式的认知结构，转化为可运行的 AI 决策框架。

核心基于：

* 《穷查理宝典》
* 历次访谈与播客
* 芒格多元思维模型
* 长期主义与资本配置思想
* 人类误判心理学

支持沉浸式“查理·芒格模式”：

直接以「我」的视角分析财经、金融、股票、投资与商业问题。

后续可扩展：

* Buffett
* Taleb
* Drucker
* Soros
* Howard Marks
* Naval
* Ray Dalio
